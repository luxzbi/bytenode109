bytenode 코드 설명서

글 작성기에 사용하는 간단한 태그 문법입니다. 모든 명령은 <로 시작하고 >로 끝납니다.

소개

bytenode 태그는 블로그 글 안에서 텍스트 스타일, 이미지, 영상, 레이아웃을 제어합니다. 일반 텍스트는 그대로 입력하면 됩니다.

태그 안에 >를 쓰면 파서가 그 위치에서 태그를 닫아버립니다. 태그 내용에 꺽쇠 부등호를 쓰지 마세요.

작성 규칙

  • 태그는 <명령: 내용> 형식입니다.
  • 태그 안에 태그를 중첩할 수 없습니다. <indent: <mark: 내용>> 이런 형식은 동작하지 않습니다.
  • 링크는 반드시 {URL} 링크문구 형식으로 씁니다. Markdown [텍스트](URL) 문법은 사용하지 않습니다.
  • 빈 줄은 실제 세로 여백이 됩니다. 너무 많이 넣으면 큰 빈 공간이 생깁니다.
  • 이미지 경로는 실제 업로드된 경로를 사용해야 합니다.

<5t: 내용>일반 텍스트 (크기 1~9)내용
<bt: 내용>굵게내용
<it: 내용>기울임내용
<mark: 내용>형광 표시내용
<code: npm install>인라인 코드npm install
예시
<xt: 블로그 제목> <5t: 일반 크기 텍스트입니다.> <bt: 굵은 글씨> <it: 기울인 글씨> <mark: 형광펜 강조> <code: git commit -m "fix">

<color:색이름_5t: 내용> 형식으로 사용합니다. 색 이름 또는 hex 코드를 쓸 수 있습니다.

수학 기호 (LaTeX)

달러 기호로 감싸면 수학 수식이 렌더링됩니다. 인터넷 연결이 필요합니다.

문법설명예시
$수식$인라인 수식 (글 중간에)$x^2 + 1$
$$수식$$블록 수식 (가운데 큰 수식)$$\frac{b}{2a}$$
예시
<5t: 이차방정식 $ax^2 + bx + c = 0$의 해입니다.> <5t: 근의 공식: $$x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}$$>
태그 안에서 $...$를 자유롭게 사용할 수 있습니다. 수식 안에 >가 들어가면 파서가 태그를 닫아버리므로 \gt를 대신 사용하세요.

화학식

달러 기호 안에 \ce{...}를 쓰면 화학식이 렌더링됩니다. KaTeX mhchem 확장을 사용합니다.

문법설명예시
$\ce{H2O}$물 분자$\ce{H2O}$
$\ce{CO2}$이산화탄소$\ce{CO2}$
$\ce{Na+ + Cl- -> NaCl}$반응식 (화살표)$\ce{Na+ + Cl- -> NaCl}$
$\ce{H2SO4}$황산$\ce{H2SO4}$
$\ce{^{14}_{6}C}$동위원소 표기$\ce{^{14}_{6}C}$
$$\ce{A + B <=> C + D}$$가역 반응식 (블록)
예시
<5t: 물의 화학식: $\ce{H2O}$> <5t: 광합성 반응:> $$\ce{6CO2 + 6H2O -> C6H12O6 + 6O2}$$ <5t: 산화환원 반응: $\ce{Fe^{2+} -> Fe^{3+} + e-}$>

표

|로 열을 구분하고, //로 행을 구분합니다. 첫 번째 행이 헤더(굵은 배경)가 됩니다.

문법설명
<table: 헤더1|헤더2 // 값1|값2>기본 표 (첫 행 = 헤더)
<table: 값1|값2 // 값3|값4 header:no>헤더 없이 데이터만
예시 — 기본 표
<table: 원소|기호|원자번호 // 수소|H|1 // 산소|O|8 // 탄소|C|6>
예시 — 헤더 없는 표
<table: 이름|홍길동 // 학교|bytenode고 // 학년|2학년 header:no>
열 수가 일치하지 않아도 되지만, 가능하면 맞추는 게 깔끔합니다. 셀 안에 |나 //는 사용할 수 없습니다.

수학 그래프

함수식을 입력하면 인터랙티브 그래프로 표시됩니다. 줌/패닝 가능. 인터넷 연결이 필요합니다.

명령설명
<graph: y=x^2>기본 그래프 (범위 자동 -10~10)
<graph: y=x^2 range:-5,5>x축 범위 지정
<graph: y=x^2 | y=2*x+1>|로 구분해 여러 함수 동시 표시
<graph: y=sin(x) size:small>크기 지정: small / medium(기본) / large
수식은 JavaScript 수학 표현식으로 씁니다: * 곱셈 필수, ^ 거듭제곱, sin(x) cos(x) sqrt(x) abs(x) log(x) 사용 가능. y=는 생략 가능.
수식 예시의미
x^2$x^2$ (이차함수)
x^2 + 2*x + 1$x^2 + 2x + 1$
sin(x)$\sin(x)$ (삼각함수)
sqrt(x)$\sqrt{x}$ (제곱근)
1/x$\frac{1}{x}$ (반비례)
abs(x)$|x|$ (절댓값)
log(x)$\log(x)$ (로그)
exp(x)$e^x$ (지수함수)
예시 — 이차함수
<graph: y=x^2 range:-5,5>
예시 — 여러 함수 비교
<graph: y=x^2 | y=2*x+3 | y=-x+1 range:-6,6 size:large>
예시 — 삼각함수
<graph: y=sin(x) | y=cos(x) range:-6.28,6.28 size:medium>

3D 모델

GLB / GLTF 형식의 3D 모델 파일을 글 안에 삽입합니다. 마우스·터치로 회전 및 확대가 가능합니다.

명령설명
<model3d: /uploads/파일.glb>3D 모델 삽입 (기본 크기 medium)
<model3d: /uploads/파일.glb autorotate>자동 회전 활성화
<model3d: /uploads/파일.glb size:large>크기 지정: small / medium(기본) / large
지원 형식: GLB, GLTF — 파일은 미디어 업로드로 먼저 서버에 올린 뒤 경로를 복사해서 사용합니다.
최대 파일 크기: 50 MB.
autorotate와 size:는 순서 상관없이 함께 사용할 수 있습니다.
예시 — 기본
<model3d: /uploads/robot.glb>
예시 — 자동 회전 + 큰 크기
<model3d: /uploads/robot.glb autorotate size:large>

간격

명령설명
<->가로 한 칸 공백
<5->가로 N칸 공백 (숫자 지정)
빈 줄세로 여백 (많이 넣을수록 넓어짐)
<spacer: 30Q>정확한 세로 여백 (숫자 = 픽셀, 30Q = 30px)
빈 줄 여백은 실제 공간이 됩니다. 섹션 사이에는 1줄 정도만 사용하는 것을 권장합니다. 너무 많은 빈 줄은 큰 공백으로 보입니다.
예시
<5t: 왼쪽> <-> <5t: 중간> <5-> <5t: 오른쪽> <spacer: 30Q>

bytenode-flashinfo

인포그래픽 제작에 특화된 확장 모드입니다. 글쓰기 화면 상단의 모드 버튼에서 bytenode-flashinfo로 전환하면 해당 AI 프롬프트가 복사되고 비율 설정이 활성화됩니다.

기본 bytenode 태그를 모두 사용할 수 있으며, 아래의 인포그래픽 전용 태그가 추가됩니다.

stat / progress

명령설명
<stat: 값 | 라벨>큰 숫자 강조 표시
<stat: 값 | 라벨 | 색>색상 지정 (이름 또는 #hex)
<progress: 라벨 | 75%>가로 진행 막대
<progress: 라벨 | 75% | #4ade80>색상 진행 막대
예시
<stat: 98% | 고객 만족도 | #4ade80> <stat: 1,200만 | 누적 사용자 | #60a5fa> <progress: 목표 달성률 | 83% | #facc15>

예시

bytenode-flashppt — 고급 레이아웃

Canva 스타일의 구성 요소. 슬라이드 안에서 정보를 시각적으로 구조화합니다.

명령설명
<columns3: 내용1 | 내용2 | 내용3>3등분 가로 컬럼 레이아웃
<grid2x2: 제목1:설명1 | 제목2:설명2 | 제목3:설명3 | 제목4:설명4 | accent:#색>2×2 정보 그리드. accent로 강조색 지정
<textglow: #색1,#색2 | 텍스트 | 크기>빛번짐 글로우 그라데이션 텍스트. 크기 1~9
<annotate: 텍스트 | #색>포스트잇 스타일 어노테이션 메모 박스
<comparison: A라벨 | B라벨 // 항목 | A값 | B값 // ...>A vs B 나란히 비교 테이블. //로 행 구분
<accent: #색 | 텍스트>왼쪽 컬러 바 강조 인용 박스
<magazine: 이미지URL | 제목 | 내용 | left/right>이미지 + 텍스트 에디토리얼 레이아웃
columns3 예시

byteexam 1s — 시험지 구조

byteexam은 전용 DSL 형식으로 시험지를 작성합니다. HTML·마크다운과 완전히 다른 문법이며, 반드시 ---BYTEEXAM-START---와 ---BYTEEXAM-END--- 사이에 작성합니다.

AI에게 코드를 생성할 때는 byteexam 앱(byteexam109.vercel.app)의 프롬프트 생성기를 사용하면 시험 범위·난이도를 입력해 맞춤 프롬프트를 자동 생성할 수 있습니다.

[HEADER] 블록

필드설명예시
title=시험지 제목2025 1학기 중간고사
subject=과목·단원공통수학1 — 다항식
difficulty=난이도기본 / 실력 / 대전권기출 / 강남8학군 / 모의고사변형 / 과학고+영재고
date=시험 날짜2025-06-01
total=총 문항 수20

[QUESTION] 블록 — 공통 필드

필드설명
num=문항 번호 (1부터 순서대로)
type=문항 유형 — 아래 표 참고
text=문제 본문. 조건 설명 + 구하는 것을 반드시 포함
answer=정답 번호 또는 답 텍스트
point=배점 (정수)
explain=해설 — 풀이 단계 + 오답 선지별 오류 원인

[ANSWER_SHEET] 블록

---BYTEEXAM-END--- 직전에 반드시 포함. 문항 번호와 정답을 나열합니다.

전체 구조 예시
---BYTEEXAM-START--- [HEADER] title=2025 1학기 중간고사 subject=공통수학1 — 다항식 difficulty=실력 date=2025-06-01 total=3 [QUESTION] num=1 type=5choice text=다항식 $f(x) = x^3 - 2x + 1$을 $x-1$로 나눈 나머지를 구하시오. choice1=① 0 choice2=② 1 choice3=③ 2 choice4=④ 3 choice5=⑤ 4 answer=1 point=3 explain=나머지 정리에 의해 f(1)=1-2+1=0이므로 나머지는 0. [ANSWER_SHEET] 1=① ---BYTEEXAM-END---
